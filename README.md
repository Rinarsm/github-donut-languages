# GitHub Donut Languages

Dynamic GitHub top languages card with customizable donut colors and themes.

## Features

- Dynamic GitHub language statistics
- Donut chart visualization
- Custom donut color palette
- Built-in themes
- Custom background, text, title, border, and ring colors
- Adjustable donut thickness
- Adjustable segment gaps
- Language exclusion
- Optional fork inclusion
- Optional percentage display
- Configurable top language count
- Response caching

## Available Themes

- `purple`
- `midnight`
- `rose`
- `ocean`
